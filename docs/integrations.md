# 외부 도구 연동 지점

이 앱에 가격 자료가 들어오는 길은 다섯 가지다. 화면의 자료 목록에 어느 길로 들어왔는지(입력 경로)가 표시된다.

| 입력 경로 | 표시 | 누가 넣는가 |
|---|---|---|
| `MANUAL` | 직접 입력 | 사용자가 폼에 입력 |
| `CSV` | CSV 가져오기 | 사용자가 CSV 파일을 올림 |
| `API` | 공식 API 조회(앱 내 연동) | 앱 안에 등록된 `PriceProvider`가 서버에서 조회. **현재 등록된 제공자 없음** |
| `CLIP` | 확장으로 직접 담기 | 브라우저 확장. 사용자가 보고 있던 페이지 한 건을 버튼을 눌러 저장 |
| `EXTERNAL` | 외부 도구 가져오기 | 가져오기 API를 호출하는 로컬 프로그램 |

**이 저장소는 수집기(크롤러·스크레이퍼)를 제공하지 않는다.** 서버는 외부 매물 사이트에 요청하지 않고, 확장은 사용자가 이미 열어 본 페이지를 사용자가 버튼을 누를 때 한 번만 읽는다. 외부 도구가 연결할 수 있는 지점은 아래 두 곳이다.

## 1. 가져오기 API

로컬 프로그램이 가격 자료를 넣는 유일한 쓰기 API다. 구현: `src/lib/import/`, `src/app/api/import/`.

### 켜기

기본은 꺼져 있다. 앱의 **설정**(`/settings`)에서 가져오기 토큰을 만들면 켜진다. 토큰 원문은 만든 직후 한 번만 보이고 DB에는 SHA-256 해시만 저장된다. 재발급하면 이전 토큰은 바로 못 쓰게 되고, 폐기하면 API가 꺼진다.

### `POST /api/import/prices`

```bash
curl -sS http://127.0.0.1:3000/api/import/prices \
  -H "Authorization: Bearer $RESALE_IMPORT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"itemId": 1, "records": [{"price_type": "ASKING", "amount": 15000, "source_name": "예시마켓", "source_url": "https://example.com/items/101", "external_id": "101", "checked_date": "2026-11-01"}]}'
```

- 본문: `{ "itemId": <물건 번호>, "records": [ ... ] }`. 레코드의 필드는 CSV 열과 이름·의미가 같다(README의 "CSV 형식"). 값은 문자열 또는 숫자.
- **CSV 열에 없는 필드가 하나라도 있으면 그 행을 거부한다.** 판매자 닉네임·연락처·프로필·위치 같은 정보는 받을 칸이 없다.
- 응답: `{ "imported": n, "rejected": m, "results": [{ "index": 0, "ok": true, "id": 12 }, { "index": 1, "ok": false, "error": "..." }] }`. 일부 행이 실패해도 올바른 행은 저장한다.
- 한 번에 최대 100건, 본문 256KB. `Content-Type: application/json` 필수.
- 저장 규칙은 다른 경로와 같다. 같은 검증(`price-input.ts`)과 같은 저장 함수(`insertPrice`)를 거친다.
  - `VERIFIED_SALE`은 만들 수 없다. 해당 행은 오류로 거부되고 다른 유형으로 바뀌지 않는다.
  - 같은 매물(출처+매물 번호 또는 정규화 URL)은 중복으로 거부된다.
  - **항상 실제 사용 모드의 물건에만 저장한다.** 데모 물건 번호는 404다.
- 입력 경로(`CLIP`/`EXTERNAL`)는 요청이 주장할 수 없고 서버가 `Origin`으로 정한다.

### `GET /api/import/items?q=<검색어>`

연결할 물건을 고르기 위한 목록(최대 50건). 같은 토큰이 필요하고, 실제 모드 물건의 번호·이름·식별정보·카테고리·상태만 돌려준다.

### 접근 통제

| 확인 | 내용 |
|---|---|
| `Host` | 루프백 주소가 아니면 403 (기존 장치, DNS 리바인딩 방어) |
| `Origin` | 없음(브라우저가 아닌 로컬 도구) 또는 설정에 등록한 확장(`chrome-extension://<ID>`)만 허용. 일반 웹사이트·등록하지 않은 확장·이 앱 자신의 화면은 403 |
| 토큰 | `Authorization: Bearer <토큰>`. 해시끼리 상수 시간 비교. 없거나 틀리면 401, 토큰을 만들지 않았으면 403 |
| CORS | 등록한 확장 origin에만 허용 헤더를 돌려준다. `*`는 쓰지 않는다 |

토큰은 응답·오류 문구·로그에 넣지 않는다. 토큰을 아는 로컬 프로그램은 물건 목록을 읽고 가격 자료를 추가할 수 있으므로, 쓰지 않을 때는 폐기해 둔다.

## 2. `PriceProvider` (앱 내 공식 가격 제공자)

`src/lib/providers/price.ts`의 인터페이스다. 접근 권한을 확보한 **공식 가격 API**가 생겼을 때 앱 안에 붙이는 자리이고, 지금은 등록된 제공자가 없다(테스트로 고정). 제공자가 실제 체결가를 제공한다고 공식 문서로 확인된 경우에만 `attestsVerifiedSales`를 켤 수 있고, 그때도 검증 근거를 함께 저장해야 한다. 가져오기 API와 확장은 이 경로가 아니므로 `VERIFIED_SALE`을 만들 수 없다.

## 외부 도구를 만드는 사람의 책임

가져오기 API는 "자료를 받는 문"일 뿐이다. 그 자료를 어디서 어떻게 얻었는지는 도구를 만든 사람의 책임이다.

- 자료를 얻는 사이트의 **이용약관과 robots.txt를 직접 확인**한다. 화면에 보인다는 이유로 자동 수집이 허용되는 것은 아니다.
- **접근 차단을 우회하지 않는다.** 로그인·CAPTCHA·봇 탐지·속도 제한을 피하거나 속이는 수단을 쓰지 않는다.
- **개인정보를 수집하지 않는다.** 판매자 닉네임·연락처·프로필·채팅·위치는 이 앱에 넣을 수도 없다.
- 가격의 의미를 정직하게 표시한다. 판매 중이면 `ASKING`, 판매완료 표시가 있는 게시글이면 `SOLD_LISTING`이고, 판별하지 못하면 보내지 않는다.
- 이 문서와 이 저장소는 어떤 사이트의 데이터 이용·재배포 권한도 보장하지 않는다.

## 브라우저 확장 "직접 담기"

`extension/` 디렉터리. 설치와 사용법은 README, 크롤링이 아닌 이유는 [data-sources.md](data-sources.md)에 있다.

| 권한 | 이유 |
|---|---|
| `activeTab` | 사용자가 확장 버튼을 누른 그 탭 하나에만, 그때만 접근한다 |
| `scripting` | 그 탭의 문서를 읽는 스크립트를 주입한다. Manifest V3에서는 `activeTab`만으로 주입할 수 없다. 이 권한 자체는 어떤 사이트 접근도 주지 않는다 |
| `storage` | 가져오기 토큰을 이 브라우저에 저장한다 |
| host `http://127.0.0.1:3000/*` | 로컬 앱으로 저장 요청을 보낸다. 다른 host 권한은 없다 |

백그라운드 스크립트와 콘텐츠 스크립트가 없어 사용자의 클릭 없이 실행되는 코드가 없다. 이 경계는 `extension/tests/boundaries.test.ts`가 확인한다.
