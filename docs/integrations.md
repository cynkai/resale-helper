# 외부 도구 연동 지점

이 앱에 가격 자료가 들어오는 길은 다섯 가지다. 화면의 자료 목록에 어느 길로 들어왔는지(입력 경로)가 표시된다.

| 입력 경로 | 표시 | 누가 넣는가 |
|---|---|---|
| `MANUAL` | 직접 입력 | 사용자가 폼에 입력 |
| `CSV` | CSV 가져오기 | 사용자가 CSV 파일을 올림 |
| `API` | 공식 API 조회(앱 내 연동) | 앱 안에 등록된 `PriceProvider`가 서버에서 조회. **현재 등록된 제공자 없음** |
| `CLIP` | 확장으로 직접 담기 | 브라우저 확장. 사용자가 보고 있던 페이지 한 건을 버튼을 눌러 저장 |
| `EXTERNAL` | 외부 도구 가져오기 | 가져오기 API를 호출하는 로컬 프로그램 |

**이 저장소는 수집기(크롤러·스크레이퍼)를 제공하지 않는다.** 서버는 외부 매물 사이트에 요청하지 않고, 확장은 사용자가 이미 열어 본 페이지를 사용자가 버튼을 누를 때 한 번만 읽는다. 외부 도구가 연결할 수 있는 지점은 아래 두 곳이다.

## 1. 가져오기 API

로컬 프로그램이 가격 자료를 넣는 유일한 쓰기 API다. 구현: `src/lib/import/`, `src/app/api/import/`.

### 켜기

기본은 꺼져 있다. 앱의 **설정**(`/settings`)에서 가져오기 토큰을 만들면 켜진다. 토큰 원문은 만든 직후 한 번만 보이고 DB에는 SHA-256 해시만 저장된다. 재발급하면 이전 토큰은 바로 못 쓰게 되고, 폐기하면 API가 꺼진다.

### `POST /api/import/prices`

```bash
curl -sS http://127.0.0.1:3000/api/import/prices \
  -H "Authorization: Bearer $RESALE_IMPORT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"itemId": 1, "records": [{"price_type": "ASKING", "amount": 15000, "source_name": "예시마켓", "source_url": "https://example.com/items/101", "external_id": "101", "checked_date": "2026-11-01"}]}'
```

- 본문: `{ "itemId": <물건 번호>, "records": [ ... ] }`. 레코드의 필드는 CSV 열과 이름·의미가 같다(README의 "CSV 형식"). 값은 문자열 또는 숫자.
- **CSV 열에 없는 필드가 하나라도 있으면 그 행을 거부한다.** 판매자 닉네임·연락처·프로필·위치 같은 정보는 받을 칸이 없다.
- 응답: `{ "imported": n, "rejected": m, "results": [{ "index": 0, "ok": true, "id": 12 }, { "index": 1, "ok": false, "error": "..." }] }`. 일부 행이 실패해도 올바른 행은 저장한다.
- 한 번에 최대 100건, 본문 256KB. `Content-Type: application/json` 필수.
- 저장 규칙은 다른 경로와 같다. 같은 검증(`price-input.ts`)과 같은 저장 함수(`insertPrice`)를 거친다.
  - `VERIFIED_SALE`은 만들 수 없다. 해당 행은 오류로 거부되고 다른 유형으로 바뀌지 않는다.
  - 같은 매물(출처+매물 번호 또는 정규화 URL)은 중복으로 거부된다. 거부한 행의 결과에는 `duplicateOf`(이미 저장된 가격 자료 번호)와 `changed`(보낸 유형·금액·통화가 저장된 값과 다른지)가 붙는다. 저장된 금액 자체는 돌려주지 않고, 자동으로 갱신하지도 않는다. 가격이 바뀌었으면 앱에서 그 자료를 수정한다.
  - 휴지통에 같은 매물이 있으면 거부하고, 고칠 수 없는 자료이므로 `duplicateOf`를 붙이지 않는다.
  - **항상 실제 사용 모드의 물건에만 저장한다.** 데모 물건 번호는 404다.
- 입력 경로(`CLIP`/`EXTERNAL`)는 요청이 주장할 수 없고 서버가 `Origin`으로 정한다.

### 예시 스크립트

[`examples/import-prices.mjs`](../examples/import-prices.mjs)는 내가 정리해 둔 JSON 파일([`examples/import-prices-example.json`](../examples/import-prices-example.json) 모양)을 읽어 100건씩 나눠 보내고 행마다 결과를 보여 준다. 로컬 파일만 읽고 요청은 내 컴퓨터의 앱으로만 보낸다(다른 포트는 `RESALE_APP_ORIGIN=http://127.0.0.1:<포트>`, 그 밖의 주소는 거부). 토큰은 환경변수 `RESALE_IMPORT_TOKEN`에서 읽고 화면에 찍지 않는다.

```bash
node examples/import-prices.mjs examples/import-prices-example.json
```

### `GET /api/import/items?q=<검색어>`

연결할 물건을 고르기 위한 목록(최대 50건). 같은 토큰이 필요하고, 실제 모드 물건의 번호·이름·식별정보·카테고리·상태만 돌려준다.

### 접근 통제

| 확인 | 내용 |
|---|---|
| `Host` | 루프백 주소가 아니면 403 (기존 장치, DNS 리바인딩 방어) |
| `Origin` | 없음(브라우저가 아닌 로컬 도구) 또는 설정에 등록한 확장(`chrome-extension://<ID>`)만 허용. 일반 웹사이트·등록하지 않은 확장·이 앱 자신의 화면은 403 |
| 토큰 | `Authorization: Bearer <토큰>`. 해시끼리 상수 시간 비교. 없거나 틀리면 401, 토큰을 만들지 않았으면 403 |
| CORS | 등록한 확장 origin에만 허용 헤더를 돌려준다. `*`는 쓰지 않는다 |

토큰은 응답·오류 문구·로그에 넣지 않는다. 토큰을 아는 로컬 프로그램은 물건 목록을 읽고 가격 자료를 추가할 수 있으므로, 쓰지 않을 때는 폐기해 둔다.

### 사용 기록

- 두 엔드포인트로 온 요청은 통과·거부 모두 `import_events`에 남고 설정 화면에서 볼 수 있다: 시각, 엔드포인트, 결과(통과 / 허용되지 않은 Origin / 토큰 없음 / 토큰 틀림 / 요청 형식·크기), HTTP 상태, 입력 경로, Origin, 물건 번호, 저장·거절 건수.
- **남기지 않는 것**: 토큰, `Authorization` 헤더, 요청 본문(가격·출처·URL). 테이블에 그런 칸이 없다.
- 같은 거부 요청과 물건 목록 읽기가 연달아 오면 한 줄에 횟수만 올린다. 가격 저장은 요청마다 한 줄이다.
- 최근 500줄만 남긴다. 웹사이트가 거부될 요청을 쏟아부어도 DB가 계속 커지지 않게 하기 위한 상한이다.
- 기록에 실패해도 API 응답은 바뀌지 않는다.

## 2. `PriceProvider` (앱 내 공식 가격 제공자)

`src/lib/providers/price.ts`의 인터페이스다. 접근 권한을 확보한 **공식 가격 API**가 생겼을 때 앱 안에 붙이는 자리이고, 지금은 등록된 제공자가 없다(테스트로 고정). 제공자가 실제 체결가를 제공한다고 공식 문서로 확인된 경우에만 `attestsVerifiedSales`를 켤 수 있고, 그때도 검증 근거를 함께 저장해야 한다. 가져오기 API와 확장은 이 경로가 아니므로 `VERIFIED_SALE`을 만들 수 없다.

## 외부 도구를 만드는 사람의 책임

가져오기 API는 "자료를 받는 문"일 뿐이다. 그 자료를 어디서 어떻게 얻었는지는 도구를 만든 사람의 책임이다.

- 자료를 얻는 사이트의 **이용약관과 robots.txt를 직접 확인**한다. 화면에 보인다는 이유로 자동 수집이 허용되는 것은 아니다.
- **접근 차단을 우회하지 않는다.** 로그인·CAPTCHA·봇 탐지·속도 제한을 피하거나 속이는 수단을 쓰지 않는다.
- **개인정보를 수집하지 않는다.** 판매자 닉네임·연락처·프로필·채팅·위치는 이 앱에 넣을 수도 없다.
- 가격의 의미를 정직하게 표시한다. 판매 중이면 `ASKING`, 판매완료 표시가 있는 게시글이면 `SOLD_LISTING`이고, 판별하지 못하면 보내지 않는다.
- 이 문서와 이 저장소는 어떤 사이트의 데이터 이용·재배포 권한도 보장하지 않는다.

## 브라우저 확장 "직접 담기"

`extension/` 디렉터리. 설치와 사용법은 README, 크롤링이 아닌 이유는 [data-sources.md](data-sources.md)에 있다.

| 권한 | 이유 |
|---|---|
| `activeTab` | 사용자가 확장 버튼을 누른 그 탭 하나에만, 그때만 접근한다 |
| `scripting` | 그 탭의 문서를 읽는 스크립트를 주입한다. Manifest V3에서는 `activeTab`만으로 주입할 수 없다. 이 권한 자체는 어떤 사이트 접근도 주지 않는다 |
| `storage` | 가져오기 토큰을 이 브라우저에 저장한다 |
| host `http://127.0.0.1:3000/*` | 로컬 앱으로 저장 요청을 보낸다. 다른 host 권한은 없다 |

### 정해 둔 것 (2026-11-13)

| 항목 | 결정 | 이유 |
|---|---|---|
| `scripting` 권한 | 유지 | `activeTab`과 함께 써야 누른 탭 하나에만 주입할 수 있다. 빼면 콘텐츠 스크립트와 매물 사이트 host 권한이 필요해져 권한이 오히려 넓어진다 |
| 번개장터 | 매물 번호·주소만 읽는 지금 수준 유지 | 구조화된 상품 정보가 없다. 화면 글자에서 가격을 짐작하면 추천 매물 가격을 집을 수 있다 |
| 그 밖의 중고 사이트 | schema.org 상품 정보가 하나뿐인 페이지만 읽음 | 사이트별 파서 없이 여러 사이트를 지원하되, 출처 이름·매물 여부는 사용자가 확인한다 |
| Origin 없는 요청 | 토큰이 맞으면 허용 유지 | 로컬 도구(curl, 개인 스크립트)가 쓰는 유일한 길이다. 입력 경로는 서버가 `EXTERNAL`로 기록해 확장 자료와 섞이지 않는다 |
| 앱 주소 | `http://127.0.0.1:3000` 고정 유지 | 주소를 설정으로 바꾸게 하면 host 권한을 넓게 잡아야 한다. 다른 포트가 필요하면 `api.ts`의 `APP_ORIGIN`과 manifest의 host 권한을 함께 고쳐 빌드한다 |

백그라운드 스크립트와 콘텐츠 스크립트가 없어 사용자의 클릭 없이 실행되는 코드가 없다. 이 경계는 `extension/tests/boundaries.test.ts`가 확인한다.

### 설치와 사용

중고 매물 페이지를 보다가 **버튼을 눌러 그 한 건**을 가격 자료로 저장합니다. 자동으로 돌아다니며 모으는 도구가 아닙니다. 버튼을 누를 때만, 열려 있는 매물 상세 페이지 하나만 읽고, 매물 사이트로는 아무 요청도 보내지 않습니다([data-sources.md](data-sources.md)).

설치(개발자 모드):

```bash
pnpm ext:build
```

1. Chrome에서 `chrome://extensions` → "개발자 모드" 켜기 → "압축해제된 확장 프로그램을 로드합니다" → `extension/dist` 폴더 선택.
2. 확장 팝업 아래에 보이는 **확장 ID**를 앱의 설정 → "허용할 확장 ID"에 저장.
3. 앱의 설정에서 만든 **가져오기 토큰**을 확장 팝업에 붙여 넣고 "토큰 저장".

사용: 매물 상세 페이지에서 확장 버튼 → "이 페이지 읽기" → 연결할 물건을 찾아 고르기 → 가격 유형·가격·상태 등급·확인일을 페이지와 대조해 확인 → "앱에 저장".

- 유형은 **제안만** 합니다(판매 중 → 판매 중 희망가, 판매완료 표시 → 판매완료 게시가). 저장 전에 직접 확인하고 고릅니다.
- 읽지 못한 값은 비워 둡니다. 추측해서 채우지 않으니 직접 입력하세요.
- 지원: 당근·중고나라는 제목·가격·판매 상태·매물 번호, 번개장터는 매물 번호와 주소만(가격은 직접 입력). **그 밖의 중고 사이트**는 페이지가 schema.org 상품 정보를 하나만 공개한 경우 제목·가격·판매 상태를 읽고, 출처 이름은 호스트 이름을 제안합니다(확인·수정 필요). **사이트 구조가 바뀌면 읽지 못하게 됩니다.** 그때는 직접 입력으로 넘어갑니다.
- 권한은 `activeTab`, `scripting`, `storage`와 로컬 앱 주소(`http://127.0.0.1:3000`)뿐입니다. 판매자 정보는 읽지 않습니다.
- 확장 저장소(`chrome.storage.local`, 이 브라우저 안)에는 가져오기 토큰과, 마지막으로 저장한 물건의 번호·이름만 둡니다. 다음에 팝업을 열면 그 물건을 선택지 하나로 보여 줄 뿐 자동으로 고르지 않습니다. "지우기"를 누르면 둘 다 지웁니다.
- 앱이 `http://127.0.0.1:3000`에서 실행 중이어야 합니다(다른 포트는 지원하지 않음).

## 로컬 보안 요약

이 앱은 로그인 없이 `127.0.0.1`에서만 열리지만, 내가 방문한 웹사이트가 브라우저를 통해 `http://127.0.0.1:3000`으로 요청을 보낼 수는 있습니다. 그래서 쓰기 API는 세 가지를 모두 확인합니다.

- **Host**: localhost가 아닌 주소로 들어온 요청은 거부(DNS 리바인딩 방어).
- **Origin**: 일반 웹사이트에서 온 요청은 토큰이 맞아도 거부. 브라우저에서는 설정에 등록한 확장 한 개만, 그 외에는 Origin이 없는 로컬 도구만 허용.
- **토큰**: 설정에서 만든 토큰이 있어야 함. 앱에는 해시만 저장하고, 토큰을 만들지 않았으면 API가 꺼져 있음.

토큰을 아는 로컬 프로그램은 물건 목록을 읽고 가격 자료를 추가할 수 있습니다. 쓰지 않을 때는 설정에서 폐기해 두세요.

설정 화면의 **가져오기 API 사용 기록**에서 이 API로 온 요청을 통과·거부 모두 볼 수 있습니다(시각, 결과, Origin, 물건 번호, 저장·거절 건수). 내가 쓰지 않은 시각의 요청이나 모르는 Origin이 보이면 토큰을 폐기하세요. 토큰과 요청 내용은 기록하지 않고 최근 500줄만 남깁니다.

무엇을 막고 무엇을 막지 않는지는 [SECURITY.md](../SECURITY.md), 날짜별 변화는 [CHANGELOG.md](../CHANGELOG.md)에 있습니다.
